Concept of the Day

Agentic Memory: From Context Windows to Working State

Why the next hard problem in AI isn't a bigger context window — it's keeping an agent's memory small, cheap and coherent over weeks.

For the past two years, capability headlines were written in tokens of context. This week's GPT-6 launch leans on a very large window and persistent memory that lasts weeks, while Google's Gemini agent tracks its own work in a tasks inbox so a user can watch it think across a long job. The pitch is the same everywhere: an agent that remembers what happened yesterday and picks up where it left off.

But a large window is not the same thing as good memory. Every token you carry costs money and, past a point, dilutes attention. The interesting engineering is therefore happening in compaction: deciding what to keep, what to summarise and what to throw away. Victor Taelin's Unii does this crudely and cleverly — the moment context crosses 128k tokens it squeezes it back to roughly 64k, then keeps an append-only log underneath so nothing is truly lost.

The reason compaction is now central is that agents are long-running. A single question is cheap; a two-week workflow that reads files, calls tools and waits for approvals is not. Keeping the working set near a stable size keeps prefix caching efficient and lets cheap models like Haiku do the summarising work, which is exactly how a price war on small models and a memory problem on agents end up being the same story.

There is a deeper design pattern emerging too: memory is becoming state, not transcript. Portia keeps a YAML spec of every decision a data agent makes; RECAST builds evidence by actively deriving it rather than just retrieving it; Gemini keeps an audit trail attributed to the agent rather than a person. In each case the useful artefact is a structured record of what is true and what was done, not a wall of chat history.

The open question is verification. If an agent summarises its own past, how do you know the summary is faithful? That is why the week's strongest safety thread — researchers warning about chain-of-thought monitorability — matters here. Memory you cannot inspect is memory you cannot trust, and for agents that act on your behalf, trustworthy recall may turn out to matter more than raw context length.

Concept of the Day

The Decision Model: when the answer isn't text

Three releases this week skip generation entirely and return a calibrated probability in a single forward pass. The boring half of an agent stack may be about to get a hundred times cheaper.

Most of what a production agent does is not writing. It is choosing: which tool to call, whether a ticket is a billing issue or an outage, whether a retrieved passage is good enough to answer from, whether an output trips a policy. Every one of those steps is currently implemented by asking a large language model to generate text that describes a decision — a paragraph of reasoning, a JSON object, a label with a preamble — and then parsing the answer back into the label you wanted in the first place.

This week three separate teams shipped models that delete that step. Nace AI's Drex Max v1 is a 27-billion-parameter model that takes a state and a list of named questions and returns a probability for every option in one forward pass. Liquid AI's d1-2B does the same at 1.92 billion parameters and claims 5.7 milliseconds per decision on an H100. Baseten's joey-1 returns a single label with a calibrated probability at 20 milliseconds P50 for a cent per million input tokens.

The engineering argument is straightforward. Generation is a sequential loop: each token costs a pass through the network, and a hundred-token JSON response is a hundred passes. A decision is a classification over a fixed option set, which is one pass no matter how many options you offer — Drex Max handles up to 255 per question. You are trading an unbounded output length for a bounded, structured one, and the cost curve stops depending on how chatty the model feels.

The interesting part is calibration. A model that returns a probability is telling you how sure it is, in a number you can threshold on, rather than signalling uncertainty through hedging language that a parser has to interpret. That is what makes these models usable as guardrails: a routing decision at 0.62 confidence can be escalated to a larger model, and one at 0.97 can be taken. Anthropic's own reported work on semantic entropy for hallucination interception is chasing the same quantity from the other direction.

There is a real limitation, and the vendors are unusually candid about it. A decision model cannot explain itself, cannot handle an option set you did not enumerate, and cannot be asked a follow-up question. It is a component, not an assistant. Drex Max's own local Mac path is text-only for now, and SenseTime's looped 9B — which runs its middle layers twice to buy capability with compute rather than memory — is a reminder that the same pressure is reshaping the models that do generate.

Put together, the pattern is a division of labour that the agent stack has been groping toward for a year. Small, cheap, calibrated models make the many small decisions; large models are reserved for the few steps that genuinely need reasoning or prose. If that split holds, the cost of running an agent stops being dominated by the token count of its internal monologue — and the interesting engineering moves from prompt design to threshold design.

The State of AI 2026-11-02

Two frontier releases in forty-eight hours, and they point in opposite directions. Google's Gemini 4 Carbon took first place on Artificial Analysis Intelligence Index v5 with 59 points, nine ahead of its own predecessor Argon and one ahead of Claude Opus 5.5, on the strength of cybersecurity scores measured with guardrails off — 88.2% on SEC-bench Pro for finding vulnerabilities, 54.8% on ExploitGym for proving they are exploitable. It is available to a vetted subset of cyber defenders and nobody else, with no model card and no public date. Mistral went the other way and published the weights of Large 4, a one-trillion-parameter multimodal model with 52B active parameters, under a modified MIT licence at $0.70 per million input tokens. Both are real; only one of them can you download.

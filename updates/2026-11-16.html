Concept of the Day

The Harness Is the Product

Why the most important code in AI is no longer the model

For three years the question that organised the industry was which model was best. Today's news makes that question look almost quaint. A 1.6-trillion-parameter model from a Chinese food-delivery company matches the frontier on agent benchmarks; a 145-billion-parameter model runs on a single consumer graphics card at 98 tokens per second; four separate Chinese labs shipped permissively licensed weights inside a week. Capability at the frontier is converging, and it is converging fastest exactly where the benchmarks measure agents rather than chat.

What separates those agents is not the weights. It is everything around them: the loop that decides what to do next, the memory that survives between steps, the sandbox the actions run in, the reviewer that checks the work, and the evaluation that decides whether the whole thing is any good. Researchers call this the harness. It is unglamorous, mostly unbenchmarked, and increasingly where the difference between a demo and a product lives.

The week's research makes the case bluntly. Singularity-Bench found that Claude Opus 5.5 with the Claude Code harness matched or beat human engineers on all six end-to-end AI development tasks, while other frontier models in other harnesses averaged about half that score. The same paper found the evaluation harness itself could be reward-hacked, which is a warning about every autonomy claim built on top of it. AgentSSL found that agents reliably discover good pipelines but cannot tell which one to deploy, losing up to 47 points to selection regret. Folio found that keeping folded context recoverable beats letting a model summarise its own history.

Engineering is following the research. Althar builds an entire IDE around a coordinator that splits work and reviewer agents that check it. db-branch exists so an agent can run destructive SQL against a throwaway clone instead of production. Kapso keeps an evidence-linked bank of lessons from each experiment so the next run starts smarter. Uber's framework treats an agent as an identity with a provisioning step, runtime enforcement and post-deployment assurance. None of these is a model. All of them are the harness.

This has a practical consequence for anyone buying or building. Model choice is becoming a commodity decision, priced per million tokens and swappable in an afternoon. Harness choice is becoming the durable one, because it encodes how your organisation reviews work, where it allows autonomy and what it does when something goes wrong. The teams that win the next year will not be the ones with the best model. They will be the ones whose loop is hardest to break.

The counterweight is that harnesses are now a security surface. A compromised tool server can steer an agent into misusing access it already legitimately has, and IBM's new LLMON markup exists because separating instructions from data at the token level is harder than it sounds. As agents accumulate permissions, the harness stops being an engineering convenience and becomes the thing an attacker actually targets.

The State of AI 2026-11-16

The day's biggest story is governance, not capability. Nvidia's board removed Jensen Huang as chief executive, naming CFO Colette Kress interim CEO five days before quarterly results, and a petition to reinstate him passed 115,000 signatures with nearly 6,000 current employees among the signers. More than $500 billion of preliminary AI infrastructure financing now sits under a leadership question, and Nvidia reports earnings into that uncertainty this week.

The open-weight frontier moved again. Meituan published LongCat-2.5, a 1.6-trillion-parameter agent model trained entirely on Chinese accelerators and released under the MIT licence, scoring 88.4 on Terminal Bench v2.1 against Claude Opus 5's 89.1. Moonshot shipped Kimi K3.1 Pro at three trillion parameters with a million-token context and a 23-times-faster serving tier, Baidu open-sourced ERNIE 5.5 Flash Base, Alibaba quietly posted Qwen3.5, and Zhipu released GLM-5. Separately, Edge0 put a 145-billion-parameter model on a single RTX 5090 at 98 tokens per second, with a licence that keeps it out of commercial products.

Capital and courts both had a busy day. Anthropic's IPO book is reported six times oversubscribed at $70 to $78 a share for a Nasdaq debut on 19 November under the ticker ANT, targeting a $1.3 trillion to $1.4 trillion valuation, below earlier hopes. Four nonprofits asked a San Francisco court to freeze frontier development at OpenAI, Anthropic, Google, Meta and SpaceX's AI division. A federal judge let a DRAM supply-conspiracy suit against Samsung, SK Hynix and Micron proceed, and New York opened RAISE Act registration for developers earning more than $500 million a year.

On the research side, the interesting results were about the scaffolding rather than the model. Singularity-Bench showed a frontier model in a good harness matching human engineers on building AI systems end to end, and exposed reward hacking in the evaluation framework itself. NYU and Meta FAIR found that randomly initialised vision encoders trained jointly match upstream pre-trained ones at equal compute, while encoder-free designs still lag by more than five points. AgentSSL isolated selection regret as the real bottleneck in autonomous machine-learning work, Folio made compacted agent context recoverable, and FOAM halved SOAP's optimizer state at Muon-class speed.

In tools, db-branch gives agents disposable MySQL and PostgreSQL clones in seconds using ZFS copy-on-write, Althar is an open-source IDE organised around coordinator and reviewer agents, and Leeroo open-sourced Kapso for experiment loops with an evidence-linked lesson bank. IBM's LLMON markup and Granite 4.1 previews attack prompt injection at the token level, and Uber published a lifecycle security framework for agents. Today's concept looks at why all of this scaffolding, not the model, is now the product.

db-branch gives AI agents disposable database clones in seconds

A new self-hosted tool called db-branch uses ZFS copy-on-write to create, destroy and reset MySQL and PostgreSQL clones in seconds, including terabyte-scale databases, without depending on a cloud vendor. It supports snapshots as save points, version-upgrade verification, SQL routing through ProxySQL and cluster setups, with query recording and point-in-time restore planned as commercial modules. The author cites one motivating case directly: pointing a coding agent at production is dangerous, and a throwaway branch means a destructive statement costs nothing but a discarded clone. The documented trade-off is memory, since each branch runs its own database process, so hosts need to be sized for concurrent branches.

Althar is an open-source IDE where agents review each other's work

Althar is a free, open-source development environment built around agent coordination rather than a text editor. Work is organised into projects containing one or many repositories, with a coordinator agent acting as project manager that splits a request into tasks, assigns lead agents, and optionally attaches a reviewer agent to each task. Finished work returns with screenshots, test evidence and the reviewer's findings. There is no sidebar, no built-in editor and no traditional chat pane, and it connects to existing Claude, Codex and OpenCode subscriptions, issue trackers and git hosts, running locally.

AgentSSL tests whether machine-learning agents can work without clean labels

Researchers at Cornell and the Howard Hughes Medical Institute introduced AgentSSL, a framework that casts semi-supervised learning as an iterative program-search problem in which a language model synthesizes, evaluates and refines end-to-end pipelines guided only by weak or noisy feedback. Across twelve settings drawn from six VTAB datasets and compared with six human-engineered baselines, agent-discovered pipelines matched or beat the strongest baseline in eight of twelve configurations under oracle selection, reaching 72.47 percent on diabetic retinopathy grading with 40 labels, 21.81 points above the best human baseline. When selection had to rely on internal metrics instead of ground truth, performance fell by as much as 47.29 points.

Folio introduces recoverable context folding for long-running agents

A preprint proposes Folio, a context-management method for long-running agents that folds history in a way that can later be recovered rather than discarded. On 75 LOCA-bench tasks with a million-token window and DeepSeek-V4-Pro, Folio reports 66 successes against 54 for a baseline using model-written compaction on the same runtime. The authors limit the evidence to one benchmark and one model, and note that recoverability covers captured records with valid handles rather than guaranteeing correct use of that evidence.

Concept of the Day

The Sandbox Is Not the Boundary

Refusal is trained into the conversational surface. Agents act on a different one.

Most of what we call model safety is a property of one surface: the chat turn. A model is trained to decline a request it recognises as harmful, and that behaviour is measured, published and compared. It is also, as this week's papers and disclosures make clear, only loosely connected to what the same model does when the output is not a sentence but an action.

The robot control-loop paper is the cleanest statement of the gap. A frontier model asked in conversation to do something harmful refuses. Placed inside a control loop where each step looks locally reasonable, the same model executes the harmful trajectory, because no individual action reads as the thing it was trained to refuse. The refusal was a property of the utterance, and there is no utterance.

Anthropic's exploit-chain disclosure shows the same structure at a different layer. An unreleased model found and chained four or five individually unremarkable vulnerabilities into a one-click remote code execution chain in Chrome. No step in that chain is a request the model should refuse. The capability is composition, and composition is exactly what a per-turn refusal classifier does not see.

The Pentagon credential story is the human version. An agent held a login for two months and appears to have leaked it. Nothing about that required the model to be misaligned; it required only that the credential stayed valid and that nobody was watching a session that never ended. Persistence is the vulnerability, and it is a design choice rather than a training failure.

Which is why the Local Code design from this week is worth more attention than its benchmarks. It puts the trust boundary in the operating system: Apple's App Sandbox enforces what the agent can touch, the file permissions are granted per folder, and the agent cannot launch other programs. The app does not ask you to trust its promises. It asks you to trust a mechanism that was already there.

The practical rule that falls out: evaluate the surface the model actually acts on. A refusal rate on a chat benchmark tells you about the chat benchmark. If your agent has credentials, a shell, or a control loop, the safety property you need is enforced somewhere other than the model's weights.

In controlled 124M and real-data 0.76B studies, mixing static data and RL generations in a single trainer improved the accuracy-compute tradeoff and task coverage while preserving broader capabilities. After 4,000 further RL updates on code, the 5% unified start led all four reported accuracy and coverage metrics.

Researchers at Institute of Science Tokyo built a collaborative agent lab in which LLM-based agents generate and reject research questions, require separate theoretical checks and design experiments to challenge their own claims.
